MARTILLO REPARADOR — Minecraft Java 26.3 / Fabric Loader 0.19.5

IMPORTANTE: ESTO ES CODIGO FUENTE, NO ES UN MOD JAR YA COMPILADO.

ESTADO DE COMPROBACION:
- Se verifico que el proyecto apunta a Minecraft 26.3 y Fabric Loader 0.19.5.
- Este archivo NO se ha compilado ni probado en Minecraft 26.3.
- En el entorno de preparacion habia Java 21, pero se requiere Java 25;
  tampoco fue posible descargar Gradle/dependencias de Minecraft.

METODO A (SIN INSTALAR JAVA NI GRADLE EN TU PC): COMPILAR CON GITHUB ACTIONS
1. Crea un repositorio personal en GitHub.
2. Descomprime el ZIP del proyecto.
3. Sube TODOS los archivos y carpetas de la carpeta del proyecto a la raiz
   del repositorio, INCLUIDA la carpeta oculta .github (contiene workflows/compilar.yml).
4. En la pestana 'Actions' selecciona 'Compilar Martillo Reparador 26.3'.
5. Pulsa 'Run workflow' (o revisa la ejecucion automatica por push).
6. Si la tarea termina en verde, abre la ejecucion y baja el artifact
   'Martillo-Reparador-26.3-Fabric' en la seccion Artifacts.
7. Descomprime el artifact y copia solo el archivo .jar principal a 'mods'.
8. Instala Fabric API 0.162.0+26.3 en 'mods' si todavia no lo tienes.

SI LA TAREA FALLA: copia el texto del error que muestra GitHub Actions;
puede que haya que corregir las API de Minecraft 26.3. No se garantiza
que este prototipo compile sin cambios.

METODO B: COMPILAR EN TU WINDOWS
1. Instala JDK 25 y Gradle 9.7.1 (o versiones compatibles).
2. Extrae el proyecto en una carpeta.
3. Ejecuta COMPILAR_EN_WINDOWS.bat.
4. Si compila, el .jar estara en build\libs\.

No copies el ZIP ni los archivos .java en la carpeta 'mods'.
No se incluye codigo original del mod de Sorac Dev (derechos reservados).
